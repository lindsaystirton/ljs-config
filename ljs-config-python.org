* Python Development Setup with Elpy

** Syncing PATH Variable

Ensure Emacs knows about your PATH settings, especially if your Python environment is set up in a shell configuration file.

Handled once, centrally, in =ljs-config-appearance.org= now -- three
separate copies of this (python, eshell, appearance) were each paying
the cost of spawning a login shell to read your PATH on every startup,
adding several seconds combined for no benefit over doing it once.

** Install Elpy and Configure

#+srcname: lexical-binding-cookie
#+begin_src emacs-lisp
;;; -*- lexical-binding: t; -*-
#+end_src

#+begin_src emacs-lisp :tangle yes
(use-package elpy
  :init
  ;; Enable Elpy
  (elpy-enable)
  :config
  ;; Set Jupyter as the Python interpreter. Previously hardcoded to
  ;; Lindsay's own virtualenv (/Users/ljs46/myenv/bin/jupyter), which
  ;; broke on any other username or machine. Falls back to whatever
  ;; `jupyter' resolves to on PATH; a specific virtualenv belongs in
  ;; the per-user override file once that mechanism is rebuilt.
  (setq python-shell-interpreter (or (executable-find "jupyter") "jupyter")
        python-shell-interpreter-args "console --simple-prompt"
        python-shell-prompt-detect-failure-warning nil)

  ;; Disable native completion for Jupyter
  (add-to-list 'python-shell-completion-native-disabled-interpreters
               "jupyter")

  ;; Use Flycheck instead of Flymake for better syntax checking
  (when (require 'flycheck nil t)
    (setq elpy-modules (delq 'elpy-module-flymake elpy-modules))
    (add-hook 'elpy-mode-hook 'flycheck-mode)))
#+end_src

** Setting the Python Interpreter from a Virtual Environment

Ensure Elpy uses the Python interpreter from your virtual environment. As
above, this now falls back to whatever `python3' resolves to on PATH
rather than a hardcoded personal virtualenv -- point this at a specific
virtual environment via the per-user override file once it exists.

#+begin_src emacs-lisp :tangle yes
(setq elpy-rpc-python-command (or (executable-find "python3") "python3"))
#+end_src

** Improving Performance

Set the buffer size threshold for Elpy to improve performance in large projects.

#+begin_src emacs-lisp :tangle yes
(setq elpy-rpc-ignored-buffer-size (* 1024 1024)) ;; 1MB
#+end_src

** Custom Key Bindings

Customize key bindings for convenience. Here, we set a key binding to quickly open a Python shell.

#+begin_src emacs-lisp :tangle yes
(define-key elpy-mode-map (kbd "C-c C-p") 'run-python)
#+end_src
