#+TITLE: LJS Config Communications

* Matrix (ement.el)

Loads the Matrix identity from =ljs-config-private.el= (see
=ljs-config-private.el.example= for the placeholder) and connects via
ement.el. Defensive like the email module: if the private variable
isn't set, this loads harmlessly and just says why =C-c M= won't do
anything yet, rather than erroring.

Encrypted rooms are not readable through this yet -- that needs
Pantalaimon running alongside Emacs, added as a deliberate next step
once plain connectivity here is confirmed working.

#+begin_src emacs-lisp :lexical yes
;; -*- lexical-binding: t; -*-
(use-package ement
  :straight (ement :type git :host github :repo "alphapapa/ement.el")
  :config
  (defun ljs/matrix-connect ()
    "Connect to Matrix using the identity in `ljs-config-private.el'."
    (interactive)
    (if (not (bound-and-true-p ljs-matrix-user-id))
        (message "ljs-config: ljs-matrix-user-id not set -- see ljs-config-private.el.example.")
      (ljs/frame-remember-and-widen)
      (ement-connect
       :user-id ljs-matrix-user-id
       :password (auth-source-pick-first-password
                  :host (cadr (split-string ljs-matrix-user-id ":"))
                  :user ljs-matrix-user-id))))
  :bind
  ("C-c M" . ljs/matrix-connect))
#+end_src

* WhatsApp (wasabi.el)

A native Emacs client for WhatsApp, from the same author as ement.el
above. Talks to WhatsApp via a small local bridge process,
=wuzapi= (a separate Homebrew-installed binary, not an Emacs
package), which itself wraps the =whatsmeow= Go library. Not on
MELPA yet, so pulled directly from its git =main= branch like
=ement= above -- meaning, unlike most of this config's packages, it
has no pinned release and can change under us on a future
=straight-pull=.

First run (=M-x wasabi=) creates its own data directory under
=~/.emacs.d/wasabi/=, starts the =wuzapi= process automatically, and
prompts for a QR code to link the account -- a one-time,
interactive, phone-in-hand step, same as linking WhatsApp Web.
=wuzapi= itself needs to already be on =$PATH= (installed via
=brew install asternic/wuzapi/wuzapi=); the existing
=exec-path-from-shell= fix earlier in this config should be enough
for GUI Emacs to see it without any extra path configuration here.

#+begin_src emacs-lisp :lexical yes
;; -*- lexical-binding: t; -*-
(use-package acp)

(use-package wasabi
  :straight (wasabi :type git :host github :repo "xenodium/wasabi")
  :bind
  ("C-c W" . wasabi)
  :config
  ;; macOS Emacs isn't compiled with D-Bus support, so the default
  ;; notification backend (`notifications-notify', the freedesktop/D-Bus
  ;; system) errors on every incoming message with "Emacs not compiled
  ;; with dbus support". Not wanted anyway -- just turn it off.
  (setq wasabi-message-notification-function nil))
#+end_src
